# Intuição

Laboratório público de **probabilidade**, **cifra elíptica pedagógica** (plano Bíblia 365 / TEMI 360) e **caderno de notas** — CCV/UFC 2002–2010 e ENEM TRI / SiSU.

**Site:** [https://aldenirfilho.github.io/intuicao/](https://aldenirfilho.github.io/intuicao/)

## O que tem

| Rota | Conteúdo |
|---|---|
| `/` | Simulador de moeda e dados, histograma ao vivo, probabilidade teórica |
| `/cifra` | Cifra elíptica \(y^2 = x^3 + 2x + 3 \pmod{37}\), 18 mensagens-núcleo |
| `/ccv` | Padronização CCV (`xp = a + b z`), impacto do σ, gabarito Iezzi |
| `/tri` | ENEM 3PL + EAP, SiSU ponderado, T-score Unicamp/UFRGS |

A curva elíptica **não** é o código do INEP. O caderno ENEM deixa isso explícito: logística 3PL, integral EAP, escala \(500 + 100\theta\).

## Local

